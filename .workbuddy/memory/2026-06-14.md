### 数据收集方案
- 数据默认存储于填写者浏览器的 localStorage
- 提交后可通过"复制答卷数据"按钮将 JSON 复制到剪贴板
- 学生将 JSON 发送给老师，老师在数据管理页导入汇总
- 支持 CSV 导出用于 SPSS/Excel 分析
